# 🖥️ Operating System Learning Map

An interactive and expandable **Operating System Learning Map** built using HTML, CSS, and vanilla JavaScript. This project provides a visual way to explore important Operating System concepts through a connected tree diagram.

## ✨ Features

- **Interactive Tree Diagram:** Explore Operating System topics through expandable and collapsible branches.
- **Process Management:** Learn about processes and their related concepts.
- **Inter Process Communication (IPC):** Explore IPC types and related concepts.
- **CPU Scheduling:** Understand scheduling types and algorithms.
- **Nested Branches:** Expand subtopics to explore further concepts and explanations.
- **Smooth Animations:** Enjoy smooth transitions when expanding or collapsing branches.
- **Modern Dark UI:** Premium dark navy background with glowing blue, green, and orange accents.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.
- **Easy to Extend:** Add new topics, subtopics, algorithms, and explanations without rebuilding the entire website.
- **No Backend Required:** Runs directly in a web browser without a database or server.

## 📚 Main Topics

### 1. Process Management
Explore process-related concepts and their explanations through an expandable tree structure.

### 2. Inter Process Communication (IPC)
Learn about IPC types, their related concepts, and how processes communicate with each other.

### 3. CPU Scheduling
Explore scheduling types and important algorithms, including:

- First Come, First Served (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Round Robin (RR)
- Priority Scheduling
- Preemptive Scheduling
- Non-Preemptive Scheduling

## 🚀 Getting Started

### Option 1: Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

No installation, backend, or database setup is required.

### Option 2: Run with VS Code Live Server

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🌳 How to Use

1. Open the website.
2. Select one of the three main Operating System topics.
3. Click the arrows or expandable cards to reveal subtopics.
4. Explore deeper branches to read explanations of individual concepts.
5. Click an expanded branch again to collapse it.
